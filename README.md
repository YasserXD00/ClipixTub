## 👋 What is this?

**ClipixTub** isn't just another boring downloader. It's a high-fidelity media engine designed to make grabbing YouTube content feel premium. We use a **Python 3.11 Native Engine** for the heavy lifting and a **React + Framer Motion** frontend for that butter-smooth UI.

Whether you're dodging ads or saving memories in **4K fidelity**, ClipixTub has your back.

---

## ✨ Features

*   🚀 **Insane Performance:** Built on a virtualized Python environment for ultra-fast extraction.
*   💎 **4K Ultra HD:** Grab content in full resolution, provided the source supports it.
*   🎧 **Audiophile Grade:** Extract 320kbps MP3s directly from any video.
*   📺 **Playlists & Shorts:** Not just videos—we handle the whole catalog.
*   ⚡ **FFmpeg Powered:** Pro-grade transcoding happens right under the hood.
*   🎨 **Slickest UI:** Dark mode, micro-animations, and a layout that doesn't feel like it's from 2005.

---

## 🛠️ Tech Stack

- **Frontend:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/) + [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Backend:** [Python 3.11](https://www.python.org/) + [Uvicorn](https://www.uvicorn.org/) + [FastAPI](https://fastapi.tiangolo.com/)
- **Media Processing:** [FFmpeg](https://ffmpeg.org/) + [Pytube](https://pytube.io/)

## 🚀 Get it Running

Keep it simple. We've included batch files to handle the mess:

1.  **Backend:** Run `START_BACKEND.bat`
2.  **Frontend:** Run `START_FRONTEND.bat`
3.  **Profit:** Open [localhost:3000](http://localhost:3000)

*(Requires Python 3.10+ and Node.js installed)*
